# סקסופון מאפס 🎷

מדריך אינטראקטיבי בעברית למתחילות בנגינה בסקסופון **אלט** — בלי צורך לדעת לקרוא תווים.

## מה יש בפנים
- 11 שלבים: היכרות עם הכלי, הרכבה, תנוחה, נשימה ופיה, צליל ראשון, סי-לה-סול, קריאה בסיסית של חמשה ומשך, שירים ראשונים, הרחבת טווח, תוכנית תרגול.
- הדמיות: איור כלי לחיץ, דיאגרמות אצבעות, חמשה אינטראקטיבית, מאמן נשימה, מדידת צליל ארוך, מטרונום, ניגון הדגמה עם הדגשת צליל נוכחי.
- משחקי זיהוי ובדיקות קצרות; התקדמות נשמרת ב-localStorage.
- סרטוני YouTube (באנגלית) משובצים בכל שלב רלוונטי.

## הרצה
קובץ סטטי יחיד — פותחים את `index.html` בדפדפן, או מפעילים GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

## הערות
- אלט הוא כלי Eb: צלילי ההדגמה מוזזים בהתאם (נשמעים שישית מתחת לתו הכתוב).
- הצלילים סינתטיים (Web Audio) ולא הקלטת סקסופון.
- הסרטונים נבחרו לפי תוצאות חיפוש ולא נצפו במלואם; כדאי לבדוק לפני שימוש.
- המדריך לא מחליף מורה, במיוחד לתיקון פיה ותנוחה.
